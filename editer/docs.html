MIDI Captain Mini 6 — Documentation

Firmware 5.0 · A reference for the pedal and for the configuration editor that writes its pageN.txt files.

📄 Official Manual (English, PDF) 📄 说明书 (中文, PDF) 📄 Quad Cortex MIDI reference 📄 Synergy SYN-20IR reference

Overview

The MIDI Captain Mini 6 is a battery-capable, wireless-capable MIDI foot controller with six footswitches. In this editor and in the config files they are named:

1top left
2top middle
3top right
Abottom left
Bbottom middle
Cbottom right

Each footswitch can send MIDI (CC, Program Change, and more), drive the pedal's own functions (page changes, tap tempo, looper), and light up in colors you choose. Everything a switch does is stored per page (a preset layout). The pedal holds many pages and you step between them with the footswitches.

The shared firmware file format also lists keys 4, 5, D, and E (for larger MIDI Captain models). On the Mini 6 those are inert placeholders — only 1, 2, 3, A, B, C are physical switches.

The page files (page0.txt, page1.txt, …)

The pedal reads plain-text, INI-style files named page0.txt, page1.txt, and so on — one file per page. Each file has a [GlobalSetup] section followed by one section per footswitch ([key1], [key2], [key3], [keyA], [keyB], [keyC]). Values are wrapped in square brackets.

[GlobalSetup]
page_name = [LEAD]
ledbright = [80]
...

[key1]
keytimes = [1]
ledmode = [normal]
ledcolor0 = [0xFF0000][0xFF0000][0xFF0000]
short_up1_name = [DRIVE]
short_up1 = [1][CC][43][0]
Fixed contract. The section names, key names, ordering, and the [..] wrapping are what the firmware expects. Only the values inside the existing structure should change. This editor preserves that structure exactly; it only edits values.

Footswitch (key) settings

Each [keyN] section describes one footswitch:

SettingKeyWhat it does
Number of stepskeytimesHow many states the switch cycles through per tap (1–10). Each step can have its own color and commands.
LED modeledmodeHow the light behaves — see LED modes.
Idle colorledcolor0Color when the switch is just sitting there. Three 0xRRGGBB values (24-bit color).
Step colorsledcolor1, ledcolor2, …Color shown while the switch is on step 1, 2, …
Step nameshort_up1_name, long1_name, …Short label shown on screen for that step/trigger.
Step commandshort_up1, long1, …The MIDI/pedal command(s) that fire — see command format.
Colors are true 24-bit hex (0xRRGGBB). The editor's color wheel writes the value for you. The three repeated color values in a line correspond to the pedal's LED segments; the editor keeps them in sync.

LED modes

ModeBehavior
normalShows your chosen color for the current step.
tapBlinks in time with the current tap tempo.
selectRadio-button behavior: among all switches set to select, only one stays lit at a time. Pressing another moves the lit indicator to it.
select1–select5Five independent radio groups. Switches sharing the same number are mutually exclusive with each other, but independent from the other numbers — so you can run several radio groups on one page.

Example: set the three amp-channel switches to select1 (only the active channel lights) and two reverb A/B switches to select2 so they stay independent.

Command types & format

A command line holds one or more commands, each a run of bracket groups. Multiple commands on one step are separated by a space:

short_up1 = [1][CC][43][0] [16][CC][24][2]
TypeFormatMeaning
CC[ch][CC][cc#][value]Control Change. e.g. [1][CC][43][0] = channel 1, CC43, value 0.
CC Toggle[ch][CCT][cc#][value]Alternating CC (toggles between values on repeated presses).
Note[ch][NT][note][velocity]MIDI note on/off.
Program Change[ch][PC][program][-]Recall a preset. The program field can be a number, or value_inc/value_dec/bank_inc/bank_dec for relative moves.
Preset (page)[preset][value_inc] / [preset][value_dec]Move the MIDI Captain to the next / previous page.
Time Engine[timeengine][value_inc|value_dec|begin|stop|record|track0..9]Tap/looper engine control.
System Common[syscmn][cmd][param]Song Position / Song Select (and inc/dec/reset variants).
Real Time[realtime][start|continue|stop|systemreset]MIDI transport / clock messages.

Bank + PC example (recall a preset in a specific bank): [1][CC][32][1] [1][PC][2][-] sends Bank Select LSB = 1, then Program Change 2.

Triggers: tap vs. hold

Which line a command lives on decides when it fires:

Line prefixFires when
short_dw#On press down (immediately).
short_up#On release of a quick tap.
long#When a hold passes the hold-time threshold (while still held down).
long_up#On release after a hold.

The # is the step number (1 for the first step, 2 for the second, and so on, up to keytimes). Each trigger has a matching ..._name line for its screen label.

Pages & navigation

The pedal holds many pages; you move between them with [preset][value_inc] (next) and [preset][value_dec] (previous), usually assigned to a footswitch's hold action.

Long-press page-change gotcha. If you put page navigation on the press-down of a hold (long#), your foot is still on the switch when the new page loads. If the same switch on the destination page also has a hold action, the still-held press can fire it too — making the pedal skip a page or bounce back. Put page changes on the release of the hold (long_up#) so the switch is up before the new page appears.

Using the editor

  • Import loads a single pageN.txt; Import Folder loads a whole folder of pages as tabs.
  • Page tabs switch between loaded pages; + Page creates a new page (optionally cloned from an existing one).
  • Swap Keys exchanges every setting between two keys (e.g. Key 1 ↔ Key B).
  • Quick-fills (QC / SYN / MC) auto-fill a command; a colored badge marks which device a command targets, including after import.
  • Save to Pedal exports the active page under its own filename (e.g. page2.txt).
  • State lives in memory only — a refresh starts empty. Import your files to work, and Save to keep them.

Troubleshooting

  • Pedal skips a page on a hold: move the page-change command to long_up# (release). See Pages & navigation.
  • Wrong preset loads on another device: send Bank Select (CC0/CC32) before the Program Change, and confirm the target's MIDI channel matches your QC/SYN selector.
  • A color only "took" on one switch: make sure you set ledcolor0 (idle) and the step colors ledcolor1.. as needed; the editor's color wheel writes all segments.
  • File won't load: filenames must be page + a number + .txt for folder import to tab them; the structure must match the fixed [GlobalSetup]/[keyN] layout.
